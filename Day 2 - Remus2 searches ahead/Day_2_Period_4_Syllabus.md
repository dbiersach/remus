# Day 2, Period 4: Remus2 against Remus1 and the student pair

3:00 to 4:30. Part of [Day 2: Remus2 searches ahead](Day_2_Syllabus.md).

## Goal

The instructor's Remus2 plays the student pair's Remus1 and the student pair, so the class can observe search against random move selection.

## The big picture

The student pair types no code this period. Remus2 is finished in `Day 2 - Remus2 searches ahead/Remus2`, and it passed its tests in Period 3. The period demonstrates the instructor's engines: Remus2 plays Remus1, then each student plays the student pair's Remus2, and then, if time remains, it plays Stockfish 1500. These games do not execute the student pair's copy. Tomorrow morning the student pair copies every file of `Day 2 - Remus2 searches ahead/Remus2` into `Day 3 - Remus3 adds the biggest gains/Remus3` and starts Remus3 from those copies, so a student pair that did not finish Remus2 finishes it first.

Lucas Chess runs the student pair's own engines from the day folders. Run the supplied verifier first. Record wins, draws, losses, or unfinished games; a short round illustrates play but does not establish a reliable Elo rating or a controlled speed comparison.
